# Contributing

## Local checks

```sh
npm ci
npm test
npm run lint
npm run build
npm run share:check
```

Keep changes focused. Include tests for card state, queue behavior, approvals, and data migrations. Do not include personal cards, profiles, credentials, source exports, or generated customer material.

This project derives from [browser-use/agency](https://github.com/browser-use/agency). Keep upstream attribution in pull requests and release notes.
